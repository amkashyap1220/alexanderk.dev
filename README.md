# alexanderk.dev

My personal site: about me, my projects, my research, and stats from my GitHub.

**Live:** [alexanderk.dev](https://alexanderk.dev)

Plain HTML, CSS and JavaScript, hosted on Cloudflare.

I used AI to help write the text on this site.

## Tests

`node --test` runs the tests in `tests/` (no install needed). They cover the Chicago home value scoring in `js/chicago-home-value-model.js` and check it ranks the sample values exactly as the Python in [Home-Value-Score](https://github.com/amkashyap1220/Home-Value-Score) does.
