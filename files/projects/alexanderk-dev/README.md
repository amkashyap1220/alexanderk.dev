# alexanderk.dev

This website: my resume and projects, in a terminal you navigate by typing.

**Source:** https://github.com/amkashyap1220/alexanderk.dev

## What it is

A hand-built static site with no frameworks and no build step. It's a small zsh look-alike with a pretend filesystem, `ls`, `cd`, `cat`, `open`, tab completion and history, all on a single page.

The files you `cat` here (like this one) are real Markdown files in the repo, under `files/`.

## Built with

- HTML, CSS, JavaScript
- GitHub API (live star and commit counts in `ls -l`)
- Cloudflare Workers

## Why I made it

I wanted one place to show my work, and to explain each project as if I were teaching it, because teaching something is the best way I know to really understand it.
