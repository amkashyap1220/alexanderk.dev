WHAT IT IS

A hand-built static site with no frameworks and no build step. Every page has a working command line you can navigate with, project pages pull live star and commit counts from the GitHub API, and the whole site redeploys to Cloudflare automatically whenever I push to main.

WHY I MADE IT

I wanted one place to show my work, and to explain each project as if I were teaching it, because teaching something is the best way I know to really understand it.
