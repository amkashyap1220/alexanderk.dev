What it is

A simple, hand-built static site with no frameworks and no build step. Each project page pulls live star and commit counts from the GitHub API, and the whole site redeploys to Cloudflare Pages automatically whenever I push to the main branch.

Why I made it

I wanted one place to show my work, and to explain each project as if I were teaching it, because teaching something is the best way I know to really understand it.
