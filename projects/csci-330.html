About the course

I took CSCI 330 at NIU in spring 2021. It covered using UNIX, shell scripting, and system-level and network programming in C++. This repo has assignments 3 through 9.

  • Assignment 3: part of the cat command, rebuilt with system calls.
  • Assignment 4: a program that appends a message from the command line to the end of a file.
  • Assignment 5: a bigger cat that can print a file as hex or binary, or encoded with a Caesar cipher or a byte rotation, with options for buffer size and how many bytes to read.
  • Assignment 6: recreating command1 | command2 with fork, pipe, and dup.
  • Assignment 7: a Bash script that manages a small text database: create, insert, display, delete, and count records.
  • Assignment 8: an awk report on a sales database.
  • Assignment 9: a TCP server in C++ that sends back the files and directory listings it's asked for from a given folder.
