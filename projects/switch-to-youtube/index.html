Switch To YouTube

A free, open-source tool that moves your music library from Spotify to YouTube Music.

  • Spotify API
  • YouTube Music API
  • Open source
View on GitHub

What it is

Switch To YouTube connects to your Spotify account, reads your playlists, and recreates them on YouTube Music. It uses both platforms' APIs to handle sign-in, fetch your music, and rebuild each playlist on the other side.

Why I made it

Every tool I could find for moving playlists between services was paid. Moving playlists you already own shouldn't cost money, so I built a free, open-source option anyone can use.
