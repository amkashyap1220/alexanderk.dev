About the course

I took CSCI 241 at NIU in spring 2021. It's the second programming course, focused on data structures, recursion, searching and sorting, and algorithm complexity. This repo has my assignments from it, all in C++.

  • Assignment 0: a warm-up lab.
  • Assignment 1: insertion sort.
  • Assignment 2: Towers of Hanoi and the eight queens puzzle, solved with recursion.
  • Assignment 3: merge sort and quick sort.
  • Assignment 4: a simulator for a simple machine language (SML).
  • Assignment 5: a bank that processes transactions against a set of accounts.
  • Assignment 6: a complex number class with overloaded operators.
  • Assignment 7: converting infix expressions to postfix with a stack class.
  • Assignment 8: evaluating postfix expressions.
  • Assignment 9: a small compiler that turns a BASIC-like language into SML for the simulator from Assignment 4.
  • Assignment 10: a doubly linked list template class.
  • Assignment 11: a binary search tree template class.
  • Assignment 12: shape classes (circle, rectangle, triangle) using inheritance and virtual functions.
